# Security policy

## Scope and supported versions

This repository covers the current Mighty Markdown website and receives reports about the Mighty Markdown macOS app. App source is maintained separately. Security fixes target the current website and the latest available app release; older app releases do not have a separate maintenance commitment.

The app is currently being prepared for its first Mac App Store release. Reports about the current prerelease build are also welcome.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/Chrominskyy/mighty-markdown-site/security/advisories/new). A GitHub account is required. This channel is enabled for this repository and is visible to the maintainers, rather than the public issue tracker.

Do not put vulnerability details, exploit code, credentials, or private documents in a public issue.

Include:

- Whether the report concerns the app or website, and the affected version or URL.
- A clear description of the issue and its potential impact.
- Minimal reproduction steps and a non-sensitive proof of concept.
- Relevant macOS/browser versions and any suggested mitigation.

Only test systems and data you own or have permission to test. Do not access other users' data or disrupt GitHub's or Apple's services.

## Handling reports

Maintainers will assess the report, request additional information when needed, and coordinate remediation and disclosure through the private advisory. No fixed response time, fix deadline, or bounty is promised. Keep details private while remediation is coordinated.

Ordinary bugs and usage questions belong in [Issues](https://github.com/Chrominskyy/mighty-markdown-site/issues). Conduct concerns follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
