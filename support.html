Get in touch

For help, bug reports, feature requests, or privacy questions, open a support issue on GitHub. A GitHub account is required. Issues are public: do not include private documents, passwords, or personal information.

For a bug report, include your macOS version, app version, what happened, and steps to reproduce it. A small example using non-sensitive text is useful.

Start with a document

  1. Use File → New to create a document, or File → Open to choose an existing UTF-8 Markdown file.
  2. Choose Read, Edit, or Split to match how you want to work.
  3. Use File → Save to keep your changes. Documents remain ordinary Markdown files.

Move around and get comfortable

Use the heading outline to jump to a section or filter headings by name. Click or drag the minimap to move through a document. Open Settings to change prose and code fonts, text size, reading width, and minimap visibility.

What is supported

Headings, emphasis, lists, task lists, quotes, links, tables, and fenced code blocks. Recognized code languages include syntax highlighting. The editor supports UTF-8 documents.

Images are shown as alternative text. HTML appears as text. Math, Mermaid diagrams, footnotes, and PDF export are not currently supported. Preview synchronization follows document blocks; very large documents may take longer to render.

Requirements and availability

macOS 26 or later, on Apple Silicon or Intel. The app is being prepared for the Mac App Store and is not yet publicly available there.
