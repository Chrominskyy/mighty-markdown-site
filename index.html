##Less between you and the document.

Familiar Mac controls, thoughtful ways to move through a page, and room for the work itself.

01Three ways to work

Read comfortably, edit your Markdown, or keep source and preview together in Split mode.

02Find the next thought

Filter the heading outline to jump to a section. It works with repeated headings too.

03A minimap for long files

See where you are in the document. Click or drag anywhere on it to move.

04Room for reading

Choose prose and code fonts, adjust text size and reading width, or turn on focus mode.

05A familiar Mac

Native windows, undo, redo, find, multiple windows, and system light and dark appearances.

06Panes that stay together

In Split mode, scrolling follows source lines and document blocks, so both sides show the same passage.

Supported

Headings, emphasis, lists, task lists, quotes, links, tables and fenced code blocks with language labels. UTF-8 documents, with the original line endings kept on save.

Not yet

Math, Mermaid diagrams, footnotes and PDF export. Images show their alternative text, and HTML appears as text.
